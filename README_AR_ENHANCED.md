# Life Tracker — النسخة المحسّنة

## التحسينات
- Validate كيتبدل مباشرة فـReact بلا إعادة تحميل الصفحة.
- Edit كيبان فالقائمة مباشرة من بعد نجاح الحفظ.
- Delete كيوقف المهمة (`enabled=false`) وما كيمسحش سجل قاعدة البيانات، باش تبقى الـHistory المرتبطة بها محفوظة.
- Pro Program: تصدير JSON خفيف واستيراد JSON مع الاختيار بين Replace وMerge. Replace كيوقف المهام القديمة وكيضيف الجديدة، وما كيحذفش الـlogs عمداً.
- History Export بصيغة CSV كتتحل فـExcel.
- مواقيت الصلاة كتتحمّل من AlAdhan حسب المدينة المغربية والتاريخ الحالي، وكتحتاج الإنترنت. راجع طريقة الحساب المحلية قبل الاعتماد عليها.
- الاحتفاظ بتحسينات الموبايل.

## ملاحظات مهمة
- الإشعارات كتحتاج مفاتيح VAPID صحيحة، وendpoint ديال الاشتراك خدام، وإعداد Cron مناسب. السماح بالإشعارات من المتصفح بوحدو ما كيضمنش وصول التذكيرات.
- تكرار التذكيرات كيبقى مربوط بخطة Vercel وإعداد `vercel.json`؛ ما تفترضش أن Cron كل دقيقة خدام فـHobby.
- ما تأكدش نجاح `next build` فهاد البيئة. شغّل `npm install` ثم `npm run build` قبل النشر.
- خذ نسخة احتياطية من قاعدة البيانات قبل أي تغيير كبير أو استيراد برامج كثيرة.
